## Research areas

Self-evolving LLM agent systems, with a focus on memory architectures, meta-evolution, and multi-agent orchestration. Recent work treats the memory pipeline itself (not just its contents) as the object of optimization and builds unified codebases that let disparate memory designs be compared under a common interface.

## Recent work

- [[memevolve-meta-evolution-agent-memory-systems]] — core contributor on MemEvolve: a meta-evolutionary framework that co-evolves agents' experiential knowledge and their underlying memory architecture, plus EvolveLab, a unified codebase that re-implements twelve representative memory systems under a four-slot `BaseMemoryProvider` interface.
